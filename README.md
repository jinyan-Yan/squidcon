# 鱿鱼图标 · Squidcon

从不同作者那里下载的图标,样式各不相同 —— 有的带圆角底板,有的透明;有的内容占满画布,有的四周留白。
直接丢进项目里用同一个尺寸渲染,就会出现大小不一、风格跳脱。

鱿鱼图标让你**以其中一张图为参考**,把其余图标的样式和视觉大小统一到它。

## 核心概念:图标是三层结构

```
画布(最外层背景)  →  底板(可选的圆角矩形)  →  主内容(图标本体)
```

"样式"就藏在三层的关系里,项目做的就是把这组参数从参考图搬到目标图:

| 参数 | 从参考图读什么 |
|---|---|
| 画布 | 透明,还是某个实色 |
| 底板 | 有没有、什么颜色、占画布多大、圆角半径占比 |
| 主内容 | 长边占画布的比例 |

把这三个比例套到另一张图上,两张图渲染成同样大小时,**主内容的视觉大小就是一致的**。

> 注意:这**不是**"裁掉白边再放大到固定比例"。那样做会让留白多的图标反而变得比别的都大 ——
> 内容占比要跟着参考图走,而不是拍一个固定数字。

## 怎么用

1. 拖入若干图标(SVG / PNG / JPG)
2. 第一张自动成为**参考图**,占据左侧「参考台」
3. 其余每张在右侧**垂直压叠成一叠牌**(每张压住下一张一半),鼠标悬停浮起,点击整张置顶
4. 想让别的图当参考,点那张卡上的「设为参考」,两张卡会交换位置并重算
5. 每张卡底部各自选**格式**(SVG / PNG)和**输出尺寸**(128 / 256 / 512 / 1024),互不影响
6. 「导出全部」按每张自己的设置逐张导出

位图变不成矢量,所以 PNG/JPG 进来的图只能出 PNG;SVG 进来可以选 SVG(保留矢量)或 PNG。

## 原理

1. 把图渲染成 512px 位图,扫描像素做结构分析(`src/probe.js`)。结果按图缓存,换参考时不用重新量
   - 画布背景 = 边框上出现最多的颜色
   - 底板 = 去掉背景后填充率 ≥ 85% 且占画布一半以上的那一层(圆形的填充率是 78.5%,不会被误判)
   - 主内容 = 再去掉底板颜色后剩下的部分
2. 把结构换算成比例(`src/style.js`)
3. 目标图按比例重新合成(`src/style.js`)
   - 位图:抠出主内容 → 去掉源背景色和源底板色 → 缩放到目标占比 → 叠在参考的画布/底板上
   - SVG:把内容包进 `<g transform>` 缩放,底板用 `<rect rx>` 画出来,矢量不丢

因为用的是内容包围盒而不是 `getBBox()`,**描边(stroke)宽度会被正确计算在内**,不会被裁掉。

## 运行

```bash
npm install
npm start
```

也可以直接传文件:

```bash
npm start -- D:\icons\a.png D:\icons\b.png
```

## 打包成 exe

```bash
npm run icon          # 由 build/logo.svg 生成 build/icon.ico(改了 logo 才需要重跑)
npm run dist          # 同时产出安装包 + 免安装版
npm run dist:setup    # 只出安装包
npm run dist:portable # 只出免安装版
```

产物在 `dist/`:

| 文件 | 用途 |
|---|---|
| `IconForge-Setup-<版本>.exe` | **安装包**。双导向导可选安装目录,装完有开始菜单和桌面快捷方式,可从「应用和功能」卸载 |
| `IconForge-<版本>-portable.exe` | **免安装版**。双击即用,不写注册表、不需要管理员权限,拷到 U 盘也能跑 |

两个都是 **x64,面向 Windows 10 / 11**。安装包默认按当前用户安装(`perMachine: false`),不会弹 UAC 要管理员权限。

### 发给别人之前要知道的三件事

1. **没有代码签名,首次运行会被 SmartScreen 拦**。对方会看到「Windows 已保护你的电脑」,要点「更多信息 → 仍要运行」。这不是病毒,只是没买证书(一年几百到上千)。想彻底消掉只能买。
2. **可能被个别杀软误报**。Electron + NSIS 的打包方式自带这个毛病,加白名单即可。
3. **更新版本号再发新版**。改 `package.json` 里的 `version`,重新 `npm run dist`;安装包会覆盖升级,不用先卸载。

### 两个必须记住的技术点

- `package.json` 里的 `"asarUnpack": ["**/*.node"]` 不能删。`sharp` 和 `@resvg/resvg-js` 是原生模块,`.node` 文件无法从 `app.asar` 归档里加载,删了会在启动时崩。
- 生成的是**未签名** exe。别人第一次运行会弹「Windows 已保护你的电脑」,需要点「更多信息 → 仍要运行」。

## 目录

```
main.js            主进程:窗口 + IPC(读文件 / 转换 / 保存)
preload.js         contextBridge,只暴露 convert / save / saveAll
src/probe.js       ★ 结构探测:把图拆成 画布 / 底板 / 主内容
src/style.js       ★ 样式提取与套用(位图路线 + SVG 路线)
src/pipeline.js    总入口
renderer/          界面(原生 HTML/CSS/JS,无框架无打包)
test/analyze.js    拆解单张图,打印三层结构
test/style-demo.js 命令行跑一次转换,验证效果
examples/          样例 SVG
```

## 验证

```bash
node test/analyze.js 某张图.png             # 拆解一张图的三层结构
node test/style-demo.js 目标图 参考图 输出图  # 命令行跑一次转换
node test/check-asar.js <app.asar 路径>     # 检查打出来的包里是不是当前这版代码
```

## 已知边界

- 主内容占比用的是**长边比例**。极扁或极长的图标,视觉面积会和方形的略有差异。
- 去掉源背景色靠的是**颜色容差**。如果图标本体里有和背景同色的部分(比如白底图上的白色细节),会被一起抠掉。
- 源图若是 SVG 但自带不透明画布,矢量路线处理不掉,会自动退回位图输出。
- 全透明或全同色的图会报错(量不出内容)。

## 放进鸿蒙工程前的一个提醒

`entry/src/main/resources/base/media/` 下的资源名**只允许小写字母、数字和下划线**。
`music-note.svg` 这种带连字符的名字会被 DevEco 拒绝,导出后改名为 `music_note.svg` 再拖进去。
